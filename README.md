# Монстрятина · боссы джунглей

Модуль Foundry VTT (v13–v14, dnd5e 4+). Боссы с Боевыми действиями по системе Кармины.

**Манифест:** `https://raw.githubusercontent.com/samroaleksej-bit/elasria_module/monstryatina/module.json`

## Что внутри
- **Пульт мастера** — кнопка ☠ слева внизу или Shift+M. СИГ / РАЗР / СМЯГ / НЕЙТ для каждого Действия.
- **Плашки у всех игроков**: арт Сигнала или Разрешения на весь экран, звук, тряска, листья, туман, тень.
- **Трекер Сигнала** справа — видят все, пока Действие висит.
- **Фазы** с подсказкой по хитам (пульт сам скажет «пора фаза 2»).
- **Ритм**: в конце хода босса пульт напомнит про Сигнал (1 Действие в раундах 1–2, 2 — с 3-го).
- **Призыв**: кнопка ставит нимф вокруг токена босса.
- **Компендиум «Монстрятина · боссы»**: Серповик и Нимфа Серповика с токенами и портретами.

## Серповик
Вихрь · Тень сверху (фаза 1, наведись на цель клавишей T) · Розовый туман · Подрубить мост (с фазы 2) · Клич гнезда (призыв 3 нимф).

## Пожиратель троп
Тропа просыпается · Раскрытая пасть (наведись T) · Переваривание · Кольца (с фазы 2) · Уползти (фаза 3).
**Части тела как в ТПК** — 4 отдельных токена-актёра (Голова КД 17/60, Горло КД 14/40, Брюхо КД 15/60, Хвост КД 16/40).
«Части на сцену» на пульте ставит их цепочкой у Пожирателя. Игроки бьют по части как по обычной цели — урон сам уходит в хиты Пожирателя и в трекер на пульте.
Сломал часть — плашка всем, −1 легендарное сопротивление, токен части помечается. Урон можно вписывать и на пульте.

## Кровавый Бутон
Лицо любимого (наведись T) · Сонный выдох · Шипы роз · Сад встаёт (призыв 3 Спящих гостей) · Кровавый полив (с фазы 2, наведись T) · Корни-ноги (фаза 3).
**Кусты-сердца** на пульте: 4 куста по 25 хитов. Урон в Бутона не идёт; уничтоженный куст — плашка всем, −1 легендарное сопротивление.

## Матка роя
Зов выводка · Феромонная метка (наведись T) · Королевская стража (с фазы 2, гвардейцы) · Подъём (6 трутней) · Обвал (фаза 3).
**Выводок** на пульте: 6 типов насекомых, +1/+2/+4 каждого или случайно по к6. **Туннели**: 3 штуки, заваленный — −1 легендарное сопротивление.
Кнопка «Начало боя» в Фазах — плашка Матки со всей свитой. Настройка «Ставить призванных автоматически».

## Новый босс
`scripts/bosses.js` — объект в `BOSSES`; арты `assets/<id>/acts/<действие>-signal.webp` и `-res.webp` (+ `-none.webp` — арт «Сорвано», если нет — берётся Сигнал);
звуки `sounds/<id>/<действие>-signal.ogg`, `-res.ogg`, `none.ogg`, `phase.ogg`.
Актёры: `.build/build-actors.js` → `sh .build/pack.sh`.

## API
`Monstryatina.signal("vihr")`, `Monstryatina.resolve("vihr","full"|"soft"|"none")`, `Monstryatina.phase(2)`, `Monstryatina.summon("sickle",3)`.

Звуки: Sonniss GDC Game Audio Bundle (royalty-free), monster_sfx_pack_2 (CC0), StarNinjas sword (CC0).
