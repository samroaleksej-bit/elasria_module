# Привой · Штаб (HOMELINE)

Магазин штаб-квартиры для Cyberpunk RED в Foundry v12.

- Улучшения штаба за очки штаба (HQ IP), по 40 за улучшение и за апгрейд. Механика пересказана по бесплатному DLC «No Place Like Home» (R. Talsorian Games).
- Декор за эдди из общака: бонусов не даёт.
- Игрок оформляет заказ, мастер подтверждает. Покупка пишется в чат и в журнал.

Открыть: Shift+H, кнопка с домиком в инструментах токенов или `game.modules.get("privoy-hq").api.open()`.

Манифест: https://raw.githubusercontent.com/samroaleksej-bit/elasria_module/privoy-hq/module.json
