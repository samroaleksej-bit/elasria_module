# Кадры боя

Манифест: https://raw.githubusercontent.com/samroaleksej-bit/elasria_module/action-splash/module.json

На каждое действие в чате dnd5e — кадр на экране ведущего: портрет действующего, иконка оружия/заклинания,
портреты целей и итог (попал/промах/крит, успех/провал, урон). Клик по кадру — пропустить.
Настройки: кому показывать (ведущему/всем), место на экране, длительность, размер, какие события.
Макрос проверки: `ActionSplash.demo()`.
