# Кармина · Багровый Хор

Модуль Foundry VTT (v13–v14, dnd5e) для босс-файта с Карминой из джангл-ваншота. Заменяет оба макроса «пульта» 2.4 (мастерский и игроковский): одна установка, и всё синхронизируется само.

## Установка

Foundry → Add-on Modules → Install Module → в поле **Manifest URL**:

```
https://raw.githubusercontent.com/samroaleksej-bit/elasria_module/karmina/module.json
```

Включи модуль в мире. Игрокам ничего ставить не нужно: макрос игрока больше не нужен.

## Как пользоваться

- **Пульт** открывается кнопкой ✿ (слева внизу) или **Shift+K** (только мастер). Его можно перетаскивать, а секции сворачивать.
- **Боевые действия.** У каждого действия четыре кнопки:
  - **СИГ** — Сигнал: игроки видят плашку и трекер в углу;
  - **РАЗР** — Разрешение: полный эффект;
  - **СМЯГ** — смягчено;
  - **НЕЙТ** — сорвали.
- **Бутоны.** 11 бутонов с именами (ЛКМ — лопнул, ПКМ — спасён, Shift+клик — закрыт). Три из них живые, и это видит только мастер. Модуль сам покажет тост и плашку «ЖИВОЙ» или «СЛИШКОМ ПОЗДНО».
- **Улики.** Отмечай найденные. Кнопка «показать игрокам» открывает им трекер с эффектами улик. Сердцевина меняет подсказку Хора.
- **Проверки с выбором.** Экран с тремя подходами появляется у игроков. Каждый бросает своим персонажем, результат приходит на пульт. Мастер видит экран полупрозрачным и может работать с картой.
- **Часы Кармины** — 4 сегмента, общие для всех.
- **Фазы.** Фаза 2 и фаза 3 с плашками. Модуль подсказывает смену фазы на порогах хитов 126 и 78 (78 — в усиленном режиме).
- **Подсказки в бою.** В конце хода Кармины модуль напоминает дать Сигнал (одно действие в раундах 1–2, два с 3-го). В начале её хода он напоминает про Разрешение и регенерацию.

## Компендиумы

- **Кармина · Акторы:** Кармина (ПО 12, 253 хп), Бутон на ярусе, Пасынок.
- **Кармина · Журнал:** сценарий из 11 страниц.
- **Кармина · Макросы:** открыть пульт, часы +1, разрешить текущий Сигнал, прогнать эффекты.

## Настройки модуля

- **Папка артов.** По умолчанию `assets/Багровый хор/атаки/`, как в макросе. Нужны файлы `хор.png`, `нектар.png`, `корни.png`, `голод.png`, `танец.png`, `фаза 2.png`, `венец.png`.
- **Звуки (JSON).** Ключи `choir`, `growl`, `roots`, `splash`, `slash`, `clock`. Пустая строка выключает звук.
- **Эффекты (JSON).** Нужен Sequencer. Ключи `bloom`, `nectar`, `root`, `drain`, `cone`, `pollen`, `rise`, значения — пути к анимациям (например из JB2A). Пусто — эффект пропускается.
- **Картинки в плашках**, **Подсказывать игрокам, как сорвать Действие**, **Дублировать плашки в чат**, **Усиленная версия (с ящиком экспедиции)**, **Имена в бутонах**.
- **Тряска и вспышки экрана** — клиентская настройка, у каждого игрока своя.

## API

```js
Karmina.signal("hor"); Karmina.resolve("hor", "full"|"soft"|"none");
Karmina.clock(3); Karmina.phase2(); Karmina.clue("heart", true);
Karmina.check("korni"); Karmina.bud(4, "saved"); Karmina.panel();
```

Исходники компендиумов лежат в `.build/`. Пересборка: `python3 .build/build.py && .build/pack.sh`.
