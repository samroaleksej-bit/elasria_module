# Найт-Сити · интерактивная карта (Foundry VTT v12)

Манифест: https://raw.githubusercontent.com/samroaleksej-bit/elasria_module/night-city-map/module.json

Открыть: Shift+M, кнопка «Карта Найт-Сити» в журналах или на панели токенов, макрос `NightCityMap.open()`.
Карта: Night City 2045 (unofficial, The Writers' Cthulhu). Точки и районы — scripts/data.js.

**Модуль переехал:** https://github.com/samroaleksej-bit/night-city-map — новые версии выходят там. Установленные копии переедут сами при «Проверить обновления».
