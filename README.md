# Волшебный щит (Arcane Ward) · автоматизация

Модуль Foundry VTT (v13, dnd5e 5.x, midi-qol по желанию).

Манифест для установки:
https://raw.githubusercontent.com/samroaleksej-bit/elasria_module/arcane-ward/module.json

Что делает:
- Заклинание Ограждения ячейкой → первый раз после Долгого отдыха щит создаётся с полными Хитами (2 × ур. волшебника + мод. Инт), дальше восстанавливает 2 × уровень ячейки.
- Активность «Подзарядить щит» (Бонусное действие, тратит ячейку) → +2 × уровень ячейки.
- Урон по волшебнику (уже после сопротивлений) сначала снимается со щита, остаток проходит.
- Долгий отдых → щит развеивается.
- Хиты щита видны как «использования» предмета; карточка в чате и всплывающие цифры над токеном.
- Предмет «Волшебный щит/оберег» модуль чинит сам при запуске мира.

Макросы: `ArcaneWard.hp(actor)`, `ArcaneWard.set(actor, 10)`, `ArcaneWard.reset(actor)`.
