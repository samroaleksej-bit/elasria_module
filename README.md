# Весы Аматуса

Полоска Света и Тьмы поверх экрана Foundry. Видна всем, двигает мастер.

- Кнопки ◐ / ◑ по бокам (видны только мастеру). Shift — шаг 2. ПКМ по полоске — сброс в 0.
- Шкала от −10 (Чистый Свет) до +10 (Чистая Тьма), стадии: ≤−10, ≤−5, равновесие, ≥5, 10.
- При смене стадии в чат уходит карточка с текстом.
- Макросы: `game.amatusBalance.light(1, "посочувствовал мёртвому богу")`, `game.amatusBalance.dark(2, "оставил Свет у порога")`, `game.amatusBalance.set(0)`.

## Раскол (v1.1)

- `game.amatusBalance.split("light", "причина")` — Свет остаётся у Порога (или `"dark"`). У всех на экране: трещина, вспышка, тряска, осколки, надпись «РАСКОЛ». Потом потерянная половина экрана остаётся обесцвеченной, по центру тлеет трещина, на полоске потерянная сторона заштрихована.
- `game.amatusBalance.merge("причина")` — половины соединяются, надпись «ЦЕЛОЕ».
- `game.amatusBalance.previewSplit("light")` / `previewMerge("light")` — проиграть эффект только у себя, без смены состояния.
- Пока раскол, весы не уходят в потерянную сторону (выключается в настройках модуля).
