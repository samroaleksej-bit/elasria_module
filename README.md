# Королева пиратов · мобьё

Модуль Foundry VTT (v13-v14, dnd5e 5+). Компендиум актёров для финала мини-кампании «Пиратская королева мертва».

**Манифест:** `https://raw.githubusercontent.com/samroaleksej-bit/elasria_module/koroleva-piratov-mobs/module.json`

## Что внутри
Компендиум «Королева пиратов · мобьё»: Командор Морского Ордена (фаза 1), Командор-Стит Ци (фаза 2), Капитанша Дозора, Сержант с якорем, Маг прилива, Отряд Дозора, Солдат, Стрелок, Тюремщик.
