# Спасти Гномреган! · Штаб операции

Модуль Foundry VTT (v13–v14) для мини-кампании «Спасти Гномреган!».

- **Штаб мастера** (клавиша J): журнал приключения по сессиям, задания и раздатки сцены прямо на странице.
- **Задания и раздатки** скрыты от игроков, пока мастер их не откроет. У игроков всплывает «Новое задание!» / «Новая раздатка!».
- **Карта Хинкла** с меткой «Вы здесь».

Нужен импортированный модуль приключения «Гномреган» (журнал «Приключение»): штаб читает его текст прямо из мира.

Манифест: `https://raw.githubusercontent.com/samroaleksej-bit/elasria_module/gnomregan/module.json`
