# Карточки героев

Модуль для Foundry VTT v13, система dnd5e. Мастер показывает карточку героя всем игрокам: она вылетает, переворачивается и листается как книжка - лист персонажа, все умения, заклинания, снаряжение.

## Установка

В Foundry: «Установить модуль» - вставить ссылку на манифест:

```
https://raw.githubusercontent.com/samroaleksej-bit/elasria_module/hero-cards/module.json
```

## Как пользоваться

- Пульт: круглая кнопка ✦ справа внизу или Shift+H. Видит только мастер.
- Клик по лицу героя в пульте - карточка у всех игроков.
- «◎ Токен» - карточка выделенного токена, подходит для NPC.
- Клик по карточке - переворот. Стрелки ‹ › или клавиши ← → - листать.
- ✕ или Esc - закрыть у всех.
- 🖼 и цвет под героем - своя картинка (лучше 16:9) и цвет подсветки.
- Надпись на рубашке: «Настройки - Карточки героев - Надпись на карточке».

## Для макросов

```js
const hc = game.modules.get("hero-cards").api;   // или просто HeroCards
hc.show(actorOrId, { art, accent, particles });
hc.showToken();
hc.next();
hc.flip();            // flip(true) / flip(false)
hc.page(2);           // страница оборота, счёт с нуля
hc.nextPage(); hc.prevPage();
hc.hide();
hc.debug(actorOrId);  // что модуль возьмёт из листа
```

## Проверка без Foundry

`test/index.html` - макет «мастер + 2 игрока» в трёх окнах. Запуск: `python -m http.server` в папке модуля, открыть `/test/index.html`, в консоли окна мастера вызывать `HeroCards.show("a1")`.
