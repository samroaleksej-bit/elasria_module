# Весы Аматуса

Полоска Света и Тьмы поверх экрана Foundry. Видна всем, двигает мастер.

- Кнопки ◐ / ◑ по бокам (видны только мастеру). Shift — шаг 2. ПКМ по полоске — сброс в 0.
- Шкала от −10 (Чистый Свет) до +10 (Чистая Тьма), стадии: ≤−10, ≤−5, равновесие, ≥5, 10.
- При смене стадии в чат уходит карточка с текстом.
- Макросы: `game.amatusBalance.light(1, "посочувствовал мёртвому богу")`, `game.amatusBalance.dark(2, "оставил Свет у порога")`, `game.amatusBalance.set(0)`.
