# Нахтмарк · имена и названия

Личный модуль мастера для Foundry VTT v13-v14. Заменяет имена и названия в импортированном приключении «Kadzoki - Проклятие Страда» на имена Нахтмарка - края Авангардии в сеттинге Эластрия.

Модуль работает по словарю имён. Текста приключения в нём нет: он правит документы уже в мире мастера.

## Установка

Настройка → Дополнения → Установить модуль → поле «URL манифеста»:

```
https://raw.githubusercontent.com/samroaleksej-bit/elasria_module/nachtmark/module.json
```

Нужен установленный и включённый модуль «Kadzoki - Проклятие Страда» с импортированным приключением.

## Как пользоваться

1. **Сделай копию мира.**
2. Включи модуль. Во вкладке журналов появится кнопка «Нахтмарк».
3. Окно покажет, сколько документов изменится. Нажми «Перенести в Нахтмарк».
4. Если что-то не понравилось - «Вернуть как было».

То же из макроса:

```js
game.modules.get("nachtmark").api.open();          // окно
await game.modules.get("nachtmark").api.run("preview");  // только посчитать
```

## Что меняется

Названия и тексты: папки, журналы и их страницы, сцены, имена токенов, заметки и надписи на картах, существа с биографиями, предметы с описаниями, таблицы, плейлисты.

Меняется только видимый текст. Ссылки `@UUID[...]`, броски `[[...]]` и разметка не трогаются.

## Что не меняется

- **Подписи, нарисованные на самих картах.** Это картинки.
- **Английские названия в квадратных скобках** после русских.
- **Папки видеосцен** и корневая папка сцен: собственные скрипты приключения ищут их по названию.
- **Актёр финальной формы хозяина замка**: его имя нужно скрипту приключения. Имя на токене, которое видят игроки, меняется.
- **Компендиумы приключения**: меняются только документы, импортированные в мир.

## Замена мобов

Кнопка «Мобы: заменить» ставит на сцены существ из двух других модулей: «AG Fifthpendium: The Crooked Moon» и «Grim Hollow Transformed RU». Оба должны быть установлены и включены вместе со своими зависимостями.

- Пары «кого на кого» лежат в `data/swaps.json`: имя моба в приключении и ссылка на существо в компендиуме. Статблоков в модуле нет.
- Существа-замены импортируются в папку актёров «Нахтмарк · мобы».
- Токен пересоздаётся на том же месте, с тем же идентификатором и на том же этаже.
- Если модуль с заменой не установлен, эти мобы просто остаются прежними - окно покажет, кого не нашло.
- «Мобы: вернуть» восстанавливает прежние токены из компендиума приключения. Место, куда мастер успел передвинуть токен, сохраняется.
- Меняй мобов вне боя: пересоздание токена убирает его из трекера.

Несколько замен на ступень опаснее прежних мобов. Убрать пару - удалить её строку из `data/swaps.json`.

## После обновления приключения

Если приключение обновилось или импортировано заново - открой окно и нажми «Перенести» ещё раз. Модуль сам найдёт, что изменилось. Свои правки в уже перенесённых журналах он сохраняет.

## Правка словаря

Все правила лежат в `scripts/dictionary.js`: старое имя, новое имя, падежи. После правки увеличь `DICT_VERSION` в конце файла - тогда модуль пересчитает замены от исходного текста.

Русские имена склоняются, поэтому часть замен может читаться коряво - особенно там, где у старого и нового названия разный род. Такие места проще поправить руками в журнале.
